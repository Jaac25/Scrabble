# Scrabble - Juego de Palabras en Ruby

Juego clásico de Scrabble desarrollado en Ruby y fxRuby, que permite jugar contra hasta 4 jugadores o contra la computadora (modo máquina vs jugador).

## Tecnologías utilizadas

- Ruby
- Programación orientada a objetos
- Lógica de inteligencia artificial básica para modo máquina

## Funcionalidades

- Juego completo de Scrabble con todas las reglas básicas
- Modo jugador vs jugador
- Modo jugador vs máquina con IA sencilla para tomar decisiones de jugadas
- Manejo del tablero, fichas y puntuaciones
- Validación de palabras y turnos
